FAQ

File-nya disimpen di mana? +
Di server litterbox (layanan file host temporer). Web ini cuma jembatan — file lu nggak nginep di server kami, langsung ngalir dari device lu ke sana.
Kok cuma 12 jam? +
Emang konsepnya file sementara — buat kirim-kiriman cepat, bukan nyimpen selamanya. Kalo butuh simpan lama, download lagi sebelum 12 jam habis.
Kadang link kebuka di tab baru, kenapa? +
Itu mode cadangan. Beberapa browser/settingan ngeblokir web buat baca balasan server file host-nya, jadi link-nya kami lempar ke tab baru buat lu copy manual. Hasilnya sama aja.
Ada batasan jenis file? +
Nggak ada — video, zip, apk, mp3, foto, doc, semua bisa. Yang penting max 200MB per file. Konten ilegal ya jangan, we share the burden 😌.
